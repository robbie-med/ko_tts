<p><b>Ko TTS</b>는 자연스러운 <b>한국어</b> 음성을 제공하는 안드로이드 음성 합성(TTS) 엔진입니다. 설치하면 글을 읽어 주는 모든 앱에서 쓸 수 있습니다. 전자책, 내비게이션, 스크린 리더, 언어 학습 앱 등에서요.</p>

<p>그래핀OS, CalyxOS, LineageOS처럼 구글 서비스가 없어서 쓸 만한 한국어 음성이 없던 휴대폰을 위해 만들었습니다.</p>

<p><b>기능</b></p>
<ul>
<li>휴대폰 안에서 작동하는 신경망 한국어 음성 (Supertonic 3). 읽는 내용이 어디에도 전송되지 않습니다.</li>
<li>목소리 10가지 (여성 5, 남성 5), 같은 모델로 30개 언어 추가 지원.</li>
<li>한국어 숫자 읽기: 세 시 삼십 분, 삼십팔 점 이 도, 전화번호는 한 자리씩, 가격은 만 원 단위로.</li>
<li>가벼운 앱: 음성 모델(경량 190 MB 또는 고정밀 401 MB)은 Hugging Face에서 한 번만 받고, SHA-256으로 검증합니다.</li>
<li>선택 사항: 본인의 API 키로 온라인 음성 사용 (OpenAI 호환 서비스, Google Cloud TTS, ElevenLabs).</li>
</ul>

<p><b>설정</b>: Ko TTS를 열어 음성 모델을 받은 뒤, 안드로이드 설정 → 접근성(또는 시스템) → 텍스트 음성 변환 출력에서 기본 엔진을 Ko TTS로 선택하세요.</p>

<p>휴대폰 음성은 Supertone의 Supertonic 3를 사용하며, 사칭·허위정보 등 해로운 사용을 금지하는 BigScience OpenRAIL-M 라이선스를 따릅니다.</p>
